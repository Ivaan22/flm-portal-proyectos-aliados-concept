# Alcance del MVP

## Incluye

- Alta y verificación de una organización.
- Borrador y presentación de una propuesta.
- Documentación requerida según área.
- Cola interna con filtros y estados.
- Solicitudes de información.
- Evaluación ponderada con comentarios.
- Historial de cambios y notificaciones transaccionales.

## No incluye

- Donaciones, pagos o patrocinios.
- Datos individuales de beneficiarios.
- Diagnósticos o historias clínicas.
- Decisiones automáticas.
- Portal corporativo o gestión de programas en campo.

## Criterio de éxito

Una organización puede presentar una propuesta completa y un analista puede llevarla hasta una decisión documentada sin recurrir a canales paralelos.
