# Decisiones técnicas

## TD-001: Next.js con App Router

Permite combinar páginas públicas, panel, acciones de servidor y API futura en una sola base. Componentes de servidor por defecto reducen JavaScript cliente.

## TD-002: TypeScript estricto

Los estados, roles y contratos quedan explícitos desde la demo.

## TD-003: persistencia diferida

La demo usa fixtures. Elegir base de datos, autenticación y almacenamiento solo después de validar requisitos legales, región y herramientas existentes.

## TD-004: evaluación explicable

La fórmula es código puro y visible. Un puntaje nunca toma una decisión ni supera un bloqueo de protección o documentación.

## TD-005: sistema visual propio

La skill local adapta disciplina de Taste Skill a un producto institucional accesible. No usa activos oficiales y mantiene el aviso conceptual en todas las rutas.
