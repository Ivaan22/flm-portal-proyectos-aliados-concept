# Roles y flujos

## Roles

| Rol | Responsabilidad |
| --- | --- |
| Organización solicitante | Crear, completar y responder sobre su propuesta |
| Analista | Revisar admisibilidad y pedir información |
| Evaluador | Puntuar criterios y registrar fundamentos |
| Administrador | Gestionar usuarios, criterios y auditoría |

## Flujo de presentación

`Borrador → Presentado → Revisión de admisibilidad → Información adicional → Evaluación → Decisión`

La organización siempre ve estado, fecha de actualización y próxima acción. Un rechazo requiere motivo visible para el equipo y comunicación aprobada.

## Flujo de evaluación

1. Validar documentación y elegibilidad.
2. Confirmar protección de la infancia y privacidad.
3. Evaluar criterios con evidencia.
4. Resolver discrepancias entre evaluadores.
5. Registrar decisión y fundamento.
